RUN 3 — BUG FIX + RE-VERIFY (2026-06-21 17:53 IST)
Issue: /analytics "Overall Leads" pie showed odd slice labels ("150%").
----------------------------------------------------------------
ROOT CAUSE (investigation):
  Not a math defect. computeSlices() in components/analytics/PieChart.tsx
  computes pct = Math.round(fraction * 100); for two equal slices that is
  exactly 50 each and can NEVER exceed 100. The "150%" was a TWO-LINE LABEL
  read as one number: the wedge drew the raw count ("1") on the top line and
  the percentage ("50%") on the line directly below, so the accessibility /
  snapshot reader concatenated "1" + "50%" -> "150%".

FIX (components/analytics/PieChart.tsx):
  Inside-slice <text> label changed to show the PERCENTAGE ONLY (e.g. "50%").
  Removed the stacked {s.value} line and the nested <tspan>{s.pct}%</tspan>.
  Raw count is retained in the legend and in the per-slice <title> hover
  tooltip ("New: 1 (50%)"), so no information is lost. computeSlices(),
  legend, and tooltip logic unchanged.
